## 1. この文書の目的と範囲

基本設計書で決めた画面に対して、見た目のルールを決めます。

| 章 | 内容 |
|---|---|
| 2 | デザインの方針 |
| 3〜5 | 色、文字、余白・角丸などの基本ルール |
| 6 | 部品（ボタン、カードなど） |
| 7 | 主な画面のレイアウト案 |
| 8 | 人体図（部位の分け方、部位ID、色の付け方） |
| 9 | アイコン・起動画面 |
| 10 | 動き、アクセシビリティ |
| 11 | 確認していただきたいこと |

色などの値は、CSS変数（`--color-primary` など）として `src/styles/global.css` にまとめ、画面側では直接色を書きません。

---

## 2. デザインの方針

1. **片手で、すぐ記録できる**：よく押すボタン（開始・終了・カテゴリの選択）は大きく、画面の下半分に置く。
2. **状態がひと目でわかる**：人体図の色と、数字（経過時間・残り時間・カロリー）を大きく見せる。それ以外の情報は控えめにする。
3. **落ち着いた見た目**：背景は白（ダークモードは濃い紺）、色は「状態を表すもの」と「押せるもの」にだけ使う。
4. **iPhoneになじむ**：iPhone標準の文字（ヒラギノ角ゴシック／San Francisco）を使い、外部のフォントは読み込まない（基本設計書 8章）。

## 3. 色

### 3.1 基本の色
ライトモードとダークモードは、端末の設定に合わせて自動で切り替えます。

| CSS変数 | 用途 | ライト | ダーク |
|---|---|---|---|
| `--color-bg` | 画面の背景 | `#F5F6F8` | `#111827` |
| `--color-surface` | カード、タブの背景 | `#FFFFFF` | `#1F2937` |
| `--color-text` | 本文 | `#1F2937` | `#F3F4F6` |
| `--color-text-sub` | 補足の文字 | `#6B7280` | `#9CA3AF` |
| `--color-border` | 区切り線 | `#E5E7EB` | `#374151` |
| `--color-hover` | マウスを乗せたとき | `#F0F1F4` | `#2B3545` |
| `--color-primary` | **メインの色（淡緑色）**。主要ボタン・選択中のチップ・ワイド時の選択中メニューの塗り | `#CEE6C1` | `#CEE6C1` |
| `--color-on-primary` | メインの色の上に置く文字 | `#1F3A14` | `#1F3A14` |
| `--color-primary-strong` | 白（または暗い）背景の上に置く、メイン系統の文字・線・グラフの棒・フォーカスの枠 | `#3F6B2A` | `#CEE6C1` |
| `--color-on-primary-strong` | `--color-primary-strong` の塗りの上の文字 | `#FFFFFF` | `#1F3A14` |
| `--color-danger` | 削除などの危険な操作 | `#DC2626` | `#F87171` |

**メインの色は淡緑色 `#CEE6C1` に決定**（2026-11-03）。とても明るい色なので、次のように使い分けます。
- 白い文字を乗せると読めない（コントラスト比 約1.3:1）ため、塗りの上の文字は濃い緑 `#1F3A14` にする（約10:1）。
- 白い背景の上に淡緑色の文字や線を置くと見えないため、文字・線には同じ系統の濃い緑 `#3F6B2A` を使う（白に対して約6:1）。

### 3.2 状態を表す色（人体図・凡例）
| 状態 | CSS変数 | ライト | ダーク | 意味 |
|---|---|---|---|---|
| 疲労中 | `--color-status-fatigued` | `#EF4444` | `#F87171` | 赤：まだ休ませる |
| 回復中 | `--color-status-recovering` | `#F59E0B` | `#FBBF24` | 黄：もう少し |
| 回復済み | `--color-status-recovered` | `#22C55E` | `#4ADE80` | 緑：鍛えてよい |
| 実施済み（ケア系） | `--color-status-done` | `#06B6D4` | `#22D3EE` | 水色：今日ケアした |
| 記録なし | `--color-status-none` | `#D1D5DB` | `#4B5563` | 灰：色を付けない |

- 色だけに頼らないよう、人体図の下には必ず凡例（色と名前）を表示し、部位をタップすると状態を文字で表示します（10.2）。
- 要件定義書の「回復済み（灰または緑）」は、**緑**を採用します。灰は「記録なし」に使います。

### 3.3 カレンダーの印
| 日の内容 | 印 |
|---|---|
| 筋トレ系か有酸素を含む | `--color-primary-strong` の丸 |
| ケア系だけ | `--color-status-done` の丸 |
| 今日 | 日付の数字を太字にし、枠で囲む |

## 4. 文字

| 用途 | 大きさ | 太さ | 例 |
|---|---|---|---|
| 経過時間 | 48px（等幅数字） | 700 | 計測中の `00:42:15` |
| 大きな数字 | 28px（等幅数字） | 700 | 推定カロリー、連続日数 |
| 画面の見出し | 22px | 700 | 「カレンダー」 |
| 小見出し | 17px | 700 | 「昨日やったこと」 |
| 本文・ボタン | 16px | 400／600 | |
| 補足・凡例 | 13px | 400 | 「推定値です」 |

- 文字の種類：`-apple-system, 'Hiragino Sans', 'Hiragino Kaku Gothic ProN', 'Yu Gothic UI', 'Meiryo', sans-serif`
- 数字が動くところ（経過時間など）は、桁がずれないよう等幅数字（`font-variant-numeric: tabular-nums`）にします。
- **入力欄の文字は16px以上**にします（16px未満だと、iPhoneのSafariが入力時に画面を勝手に拡大するため）。
- 行の高さは1.6（見出しは1.3）とします。

## 5. 余白・角丸・影

| 項目 | ルール |
|---|---|
| 余白 | 4の倍数（4・8・12・16・24・32px）だけを使う |
| 画面の端の余白 | コンパクト：16px、ワイド：24px |
| カードの間隔 | 12px |
| 角丸 | カード：16px、ボタン・入力欄：12px、チップ：999px（両端が丸い形） |
| 影 | ライトモードのカードだけ、ごく薄い影（`0 1px 3px rgb(0 0 0 / 8%)`）。ダークモードでは影を使わず、背景色の違いで区別する |
| 押せる部分の大きさ | 44px四方以上（F-RESP-05）。主要なボタンは高さ52px、開始ボタンは高さ72px |

## 6. 部品

| 部品 | 見た目 | 使う場所 |
|---|---|---|
| 主要ボタン | `--color-primary` の塗りつぶし、`--color-on-primary` の文字、高さ52px、横幅いっぱい | 保存、終了、ヘルスケアに送る |
| 開始ボタン | 主要ボタンを大きくしたもの（高さ72px、文字20px）。計測中は経過時間を表示する | ホーム |
| 副ボタン | 枠線と文字だけ、`--color-primary-strong` | 編集、前回と同じ |
| 危険ボタン | `--color-danger` の文字（確認ダイアログの中では塗りつぶし） | 削除、記録を破棄 |
| テキストボタン | 文字だけ | ［あとで］［閉じる］、手入力で記録 |
| カード | `--color-surface`、角丸16px、内側の余白16px | ホームの各ブロック、セッション一覧 |
| お知らせ | カードの左端に4pxの色の帯。帯の色は、注意（終了し忘れ・バックアップ）が黄、お知らせ（更新・未送信・筋肉痛）が `--color-primary-strong` | ホーム上部 |
| チップ（選択） | 丸い形の切り替えボタン。選択中は `--color-primary` の塗りつぶし＋チェックの印 | カテゴリ・種目の選択 |
| 区分の見出し | 「筋トレ系」「ケア系」の小見出しで、チップをまとめる | 計測中、手入力 |
| 入力欄 | 高さ48px、枠線1px、角丸12px、文字16px | 体重、日時、メモ |
| 確認ダイアログ | 画面中央（コンパクトでは下から出す）。危険な操作のボタンは右（下）に置く | 削除、復元、破棄 |
| トースト | 画面下部に2秒表示する短い知らせ | 「保存しました」 |
| タブ・メニュー | コンパクト：画面下部に4つ、アイコン＋文字。ワイド：左側に縦に並べる（基本設計書 3.4） | 全体 |

押せる部品は、押したときに少し暗くなり、キーボード操作のときはフォーカスの枠（`--color-primary-strong` の2pxの線）を表示します。

### 7.6 グラフ
| 部分 | デザイン |
|---|---|
| 推移 | **マーカー付きの折れ線グラフ（データラベル付き）**。線は `--color-primary-strong` の2.5px、なめらかな曲線（値をはみ出さない方式）。線の下は、上から下へ薄くなる淡緑色のグラデーション |

## 8. 人体図

### 8.1 作り方
| 項目 | 内容 |
|---|---|
| 素材 | **決定**：react-native-body-highlighter v3.2.0（MITライセンス）の**男性**の前面・背面。筋肉ごとに形が分かれており、部位ごとに色を塗れる。選定の経緯は 8.3 |
| データの持ち方 | 素材の形のデータ（SVGのパス）を、部位IDに置き換えて `src/ui/bodyMap/bodyPaths.ts` に変換して持つ。素材の部品（React Native用）そのものは読み込まない |
| 表示 | 前面と背面を横に並べる（縦横比 1:2）。各図の下に「前面」「背面」と表示する |
| 部位の指定 | 部位ごとに `g` 要素でまとめ、左右に分かれる部位（腕など）は同じ部位にまとめる |
| 色の付け方 | 部位の形の塗りの色を、状態の色（3.2）で指定する。部位の境目は `--color-surface` の線、体の輪郭は `--color-border` の線 |
| タップ | 部位をタップ（またはキーボードで選んでEnter）すると、選んだ部位を `--color-primary-strong` の太い線で囲み、人体図の下にその部位のカテゴリの状態（最後に鍛えた日時、回復予定時刻、残り時間）を表示する。もう一度押すと閉じる |
| 色を付けない部分 | 手・足・前腕・すね・ひざ・髪は、`--color-body-base`（ライト `#E5E7EB`／ダーク `#374151`）で塗り、押せないようにする |
| 記録の詳細での表示 | 小さく表示し、そのセッションで使った部位を塗る。筋トレ系は `--color-primary-strong`、ケア系だけの部位は `--color-status-done` |

### 8.2 部位IDと、カテゴリとの対応
部位IDは `src/domain/types.ts` の `BodyRegionId` と一致させます。「素材の部位名」は、素材のデータでの名前です。

| 部位ID | 部位 | 素材の部位名 | 前面 | 背面 | 属するカテゴリ |
|---|---|---|---|---|---|
| `face` | 顔 | head（前面） | ○ | | 小顔 |
| `neck` | 首 | neck | ○ | ○ | スマホ首、小顔 |
| `trapsUpper` | 僧帽筋上部 | trapezius | ○ | ○ | スマホ首 |
| `chest` | 胸（大胸筋） | chest | ○ | | 大胸筋 |
| `deltoids` | 肩（三角筋） | deltoids | ○ | ○ | 肩 |
| `biceps` | 上腕二頭筋 | biceps | ○ | | 腕 |
| `triceps` | 上腕三頭筋 | triceps | ○ | ○ | 腕 |
| `abs` | 腹（腹直筋・インナー） | abs | ○ | | 腹筋、反り腰 |
| `obliques` | 脇腹（腹斜筋） | obliques | ○ | | 腹筋 |
| `hipJoint` | 股関節まわり（内もも上部） | adductors | ○ | ○ | 股関節 |
| `lats` | 広背筋 | upper-back | | ○ | 背中 |
| `erectors` | 腰（脊柱起立筋） | lower-back | | ○ | 背中、**反り腰** |
| `glutes` | 臀部 | gluteal | | ○ | 下半身、反り腰 |
| `quads` | 大腿四頭筋（もも前） | quadriceps | ○ | | 下半身、有酸素 |
| `hamstrings` | ハムストリングス（もも裏） | hamstring | | ○ | 下半身、有酸素 |
| `calves` | ふくらはぎ | calves | ○ | ○ | 下半身、有酸素 |

- 有酸素は、`glutes`（臀部）を含めた脚全体に色を付けます。回復は管理しないため、今日行った場合は「実施済み」の色になります。

- 素材に「腸腰筋」の部位がないため、反り腰は「腹・臀部・腰」に色を付けます（2026-11-03 決定）。以前の部位ID `hipFlexors` は廃止し、保存済みのデータはデータ形式の版2で自動的に直します（基本設計書 4.4）。

- 1つの部位が複数のカテゴリに属する場合（例：臀部）の色は、基本設計書 5.4の優先度で決めます。
- この対応は `src/domain/master.ts` に登録済みです。

### 8.3 素材の選定の経緯
このリポジトリは公開設定のため、アプリに組み込んだ素材は誰でも取り出せます。そのため、**ソースへの組み込みと公開（再配布）が認められている素材**だけを使います。

| 候補 | 判断 | 理由 |
|---|---|---|
| ユーザーが提示した筋肉の人体画像 | 使わない | Adobe Stockの透かし入りの見本（有料素材）のため |
| ピクトグラム2.0（pictogram2.com） | 使わない | 素材そのものの再配布が禁止されている。また、筋肉ごとに分かれていない |
| Canvaの素材 | 使わない | ロゴ・アイコンとしての使用と、素材の単体での配布が禁止されている。また、ログインが必要で取り出せない |
| react-body-highlighter（MIT） | 見送り | 形が簡略的で、より写実的な素材があったため |
| **react-native-body-highlighter（MIT）** | **採用** | 筋肉の形が写実的で、部位ごとに色を塗れる。男性・女性の前面・背面がある |

ライセンス表示（著作権表示とMITライセンスの全文）は `public/third-party-licenses.txt` に置き、設定画面の「このアプリについて」から開けるようにしています。

## 10. 動き・アクセシビリティ

### 10.1 動き
「心地よいWeb遷移アニメーションの基本ルール6個」（https://photoshopvip.net/152964 ）を参考に、次のルールで動かします（2026-11-03 決定）。

| ルール | このアプリでの使い方 |
|---|---|
| フェード | 画面の切り替えは、すべて動きとフェード（不透明度0→100%）を組み合わせる |
| 拡大 | 手前の層として現れる画面（メニューの選択・手入力）は、96%→100%に拡大しながら現れる |
| 一貫した方向 | 階層の移動は**横方向だけ**（進む＝右から、戻る＝左から）。タブも並びの向きに合わせて横に動かす。縦の動きは「手前の層」の画面だけに使う |
| 速さ | 画面の切り替えは200〜320ms、ページ内の動き（ボタン・チップ・タブの帯）は150〜200msと、ページ内の方を速くする |
| 段階的な表示 | 画面の中のカードは、上から順に40msずつ遅らせて表示する（最大200ms） |
| 空間 | 詳しい画面は「右の奥」、戻る先は「左」、メニューの選択などは「下から重なる層」として、アプリの空間をそろえる |

**画面遷移の種類**（`src/features/navigation.ts` で決める）
| 種類 | 使う場面 | 動き | 時間 |
|---|---|---|---|
| 進む（push） | 詳しい画面へ移る（記録の詳細、種目の管理など） | 右から40px＋フェード | 280ms |
| 戻る（pop） | 「戻る」「キャンセル」 | 左から40px＋フェード | 280ms |
| タブ | 下部のタブ・左のメニュー | 並びの向きに16px＋フェード | 240ms |
| シート | メニューの選択、手入力で記録 | 下から32px、96%→100%＋フェード | 320ms |
| フェード | 置き換え（計測の開始、保存後に閉じるなど） | フェードのみ | 200ms |

- 動きの曲線は、すばやく動き出してゆっくり止まる `cubic-bezier(0.22, 1, 0.36, 1)` に統一します。
- 出ていく画面は動かさず、入ってくる画面だけを動かします。
- 押せる部品は、押したときに少し縮めて（ボタン97%、チップ95%、タブのアイコン90%）、押した感触を出します。
- 下部のタブは、すりガラスのような半透明（背景をぼかす）にし、選んでいるタブのアイコンの後ろに淡緑色の帯を出します。
- 端末の「視差効果を減らす」がオンのとき（`prefers-reduced-motion`）は、動きをなくします。
- 経過時間の表示は、数字が変わるだけにします（点滅などはしない）。

### 10.2 アクセシビリティ
- 文字と背景の明るさの差（コントラスト比）は、本文で4.5:1以上、大きな文字とアイコンで3:1以上にします。
- 色だけで状態を伝えず、凡例・文字・チェックの印を合わせて使います。
- 人体図には、画面読み上げ用の説明（例：「大胸筋：疲労中、あと38時間」）を付けます。
- 端末の文字サイズの設定を大きくしても、表示が崩れないようにします（文字の大きさは `rem` で指定）。
