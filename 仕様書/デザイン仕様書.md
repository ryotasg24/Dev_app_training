## 1. この文書の目的と範囲

基本設計書で決めた画面に対して、見た目のルールを決めます。

| 章 | 内容 |

| 3〜5 | 色、文字、余白・角丸などの基本ルール |
| 6 | 部品（ボタン、カードなど） |

色などの値は、CSS変数（`--color-primary` など）として `src/styles/global.css` にまとめ、画面側では直接色を書きません。

---

## 2. デザインの方針

1. **片手で、すぐ記録できる**：よく押すボタン（開始・終了・カテゴリの選択）は大きく、画面の下半分に置く。
2. **状態がひと目でわかる**：人体図の色と、数字（経過時間・残り時間・カロリー）を大きく見せる。それ以外の情報は控えめにする。
3. **落ち着いた見た目**：背景は白（ダークモードは濃い紺）、色は「状態を表すもの」と「押せるもの」にだけ使う。
4. **iPhoneになじむ**：iPhone標準の文字（ヒラギノ角ゴシック／San Francisco）を使い、外部のフォントは読み込まない（基本設計書 8章）。

## 3. 色

### 3.1 基本の色
ライトモードとダークモードは、端末の設定に合わせて自動で切り替えます。

| CSS変数 | 用途 | ライト | ダーク |
|---|---|---|---|
| `--color-bg` | 画面の背景 | `#F5F6F8` | `#111827` |
| `--color-surface` | カード、タブの背景 | `#FFFFFF` | `#1F2937` |
| `--color-text` | 本文 | `#1F2937` | `#F3F4F6` |
| `--color-text-sub` | 補足の文字 | `#6B7280` | `#9CA3AF` |
| `--color-border` | 区切り線 | `#E5E7EB` | `#374151` |
| `--color-hover` | マウスを乗せたとき | `#F0F1F4` | `#2B3545` |
| `--color-primary` | 押せるもの（主要ボタン、選択中のタブ） | `#2563EB` | `#60A5FA` |
| `--color-on-primary` | 主要ボタン上の文字 | `#FFFFFF` | `#0B1220` |
| `--color-danger` | 削除などの危険な操作 | `#DC2626` | `#F87171` |

★要確認：メインの色（`--color-primary`）を青にしています。好みの色があれば教えてください。

### 3.2 状態を表す色（人体図・凡例）
| 状態 | CSS変数 | ライト | ダーク | 意味 |
|---|---|---|---|---|
| 疲労中 | `--color-status-fatigued` | `#EF4444` | `#F87171` | 赤：まだ休ませる |
| 回復中 | `--color-status-recovering` | `#F59E0B` | `#FBBF24` | 黄：もう少し |
| 回復済み | `--color-status-recovered` | `#22C55E` | `#4ADE80` | 緑：鍛えてよい |
| 実施済み（ケア系） | `--color-status-done` | `#06B6D4` | `#22D3EE` | 水色：今日ケアした |
| 記録なし | `--color-status-none` | `#D1D5DB` | `#4B5563` | 灰：色を付けない |

- 色だけに頼らないよう、人体図の下には必ず凡例（色と名前）を表示し、部位をタップすると状態を文字で表示します（10.2）。
- 要件定義書の「回復済み（灰または緑）」は、**緑**を採用します。灰は「記録なし」に使います。

### 3.3 カレンダーの印
| 日の内容 | 印 |
|---|---|
| 筋トレ系を含む | `--color-primary` の丸 |
| ケア系だけ | `--color-status-done` の丸 |
| 今日 | 日付の数字を太字にし、枠で囲む |

## 4. 文字

| 用途 | 大きさ | 太さ | 例 |
|---|---|---|---|
| 経過時間 | 48px（等幅数字） | 700 | 計測中の `00:42:15` |
| 大きな数字 | 28px（等幅数字） | 700 | 推定カロリー、連続日数 |
| 画面の見出し | 22px | 700 | 「カレンダー」 |
| 小見出し | 17px | 700 | 「昨日やったこと」 |
| 本文・ボタン | 16px | 400／600 | |
| 補足・凡例 | 13px | 400 | 「推定値です」 |

- 文字の種類：`-apple-system, 'Hiragino Sans', 'Hiragino Kaku Gothic ProN', 'Yu Gothic UI', 'Meiryo', sans-serif`
- 数字が動くところ（経過時間など）は、桁がずれないよう等幅数字（`font-variant-numeric: tabular-nums`）にします。
- **入力欄の文字は16px以上**にします（16px未満だと、iPhoneのSafariが入力時に画面を勝手に拡大するため）。
- 行の高さは1.6（見出しは1.3）とします。

## 5. 余白・角丸・影

| 項目 | ルール |
|---|---|
| 余白 | 4の倍数（4・8・12・16・24・32px）だけを使う |
| 画面の端の余白 | コンパクト：16px、ワイド：24px |
| カードの間隔 | 12px |
| 角丸 | カード：16px、ボタン・入力欄：12px、チップ：999px（両端が丸い形） |
| 影 | ライトモードのカードだけ、ごく薄い影（`0 1px 3px rgb(0 0 0 / 8%)`）。ダークモードでは影を使わず、背景色の違いで区別する |
| 押せる部分の大きさ | 44px四方以上（F-RESP-05）。主要なボタンは高さ52px、開始ボタンは高さ72px |

## 6. 部品

| 部品 | 見た目 | 使う場所 |
|---|---|---|
| 主要ボタン | `--color-primary` の塗りつぶし、白い文字、高さ52px、横幅いっぱい | 保存、終了、ヘルスケアに送る |
| 開始ボタン | 主要ボタンを大きくしたもの（高さ72px、文字20px）。計測中は経過時間を表示し、色を `--color-status-recovered` に変える | ホーム |
| 副ボタン | 枠線だけ、`--color-primary` の文字 | 編集、前回と同じ |
| 危険ボタン | `--color-danger` の文字（確認ダイアログの中では塗りつぶし） | 削除、記録を破棄 |
| テキストボタン | 文字だけ | ［あとで］［閉じる］、手入力で記録 |
| カード | `--color-surface`、角丸16px、内側の余白16px | ホームの各ブロック、セッション一覧 |
| お知らせ | カードの左端に4pxの色の帯。帯の色は、注意（終了し忘れ・バックアップ）が黄、お知らせ（更新・未送信）が青 | ホーム上部 |
| チップ（選択） | 丸い形の切り替えボタン。選択中は `--color-primary` の塗りつぶし＋チェックの印 | カテゴリ・種目の選択 |
| 区分の見出し | 「筋トレ系」「ケア系」の小見出しで、チップをまとめる | 計測中、手入力 |
| 入力欄 | 高さ48px、枠線1px、角丸12px、文字16px | 体重、日時、メモ |
| 確認ダイアログ | 画面中央（コンパクトでは下から出す）。危険な操作のボタンは右（下）に置く | 削除、復元、破棄 |
| トースト | 画面下部に2秒表示する短い知らせ | 「保存しました」 |
| タブ・メニュー | コンパクト：画面下部に4つ、アイコン＋文字。ワイド：左側に縦に並べる（基本設計書 3.4） | 全体 |

押せる部品は、押したときに少し暗くなり、キーボード操作のときはフォーカスの枠（`--color-primary` の2pxの線）を表示します。

## 8. 人体図

### 8.1 作り方
| 項目 | 案 |
|---|---|
| 素材 | ★要確認：**自作のSVG（推奨）**。単純な形（丸みのある四角や楕円の組み合わせ）の、性別を感じさせないシルエットにする。素材のライセンスを気にしなくてよく、部位の分け方を自由に決められる |
| 表示 | 前面と背面を横に並べる。縦横比はおよそ1:2.2 |
| 部位の指定 | 各部位の形に `data-region="chest"` のように部位IDを付ける。左右に分かれる部位（腕など）は、同じ部位IDの形を2つ置く |
| 色の付け方 | 部位の形の塗りの色を、CSS変数で指定する。輪郭は `--color-border` の線 |
| タップ | 部位をタップすると、その部位の状態（基本設計書 3.3 No.1）を吹き出しで表示する。小さい部位でも押しやすいよう、押せる範囲は見た目より少し広く取る |
| 色を付けない部分 | 手・足先・頭（顔以外）などは、`--color-status-none` で塗る |

| `neck` | 首 | ○ | ○ | スマホ首、小顔 |
| `trapsUpper` | 僧帽筋上部 | | ○ | スマホ首 |
| `chest` | 胸（大胸筋） | ○ | | 大胸筋 |
| `deltoids` | 肩（三角筋） | ○ | ○ | 肩 |
| `biceps` | 上腕二頭筋 | ○ | | 腕 |
| `triceps` | 上腕三頭筋 | | ○ | 腕 |
| `abs` | 腹（腹直筋・インナー） | ○ | | 腹筋、反り腰 |

## 9. アイコン・起動画面

| 項目 | 案 |
|---|---|
| アプリのアイコン | ★要確認：`--color-primary` の背景に、白いダンベルの絵。角丸は端末が自動で付けるので、正方形で作る |
| 必要なサイズ | 180px（iPhoneのホーム画面用、`apple-touch-icon`）、192px、512px、512px（maskable：周りを切り取られても絵が欠けないよう、中央80%に収める） |
| 起動画面 | `--color-bg`（ダーク時は濃い紺）の背景に、アイコンを中央に表示。端末ごとの画像は作らず、マニフェストの `background_color` を使う |
| 画面内のアイコン | ★要確認：**lucide-react（推奨）**。線で描いたシンプルなアイコン集で、無料で使える（MITライセンス）。アプリの中に組み込まれるので、外部への通信は発生しない |

`theme_color` と `background_color` は、ライトモードの `--color-bg`（`#F5F6F8`）にそろえる案です（今の仮の値は `#111827`）。

## 10. 動き・アクセシビリティ

### 10.1 動き
- 画面の切り替えや吹き出しの表示は、0.15〜0.2秒の短い動きにとどめます。
- 端末の「視差効果を減らす」がオンのとき（`prefers-reduced-motion`）は、動きをなくします。
- 経過時間の表示は、数字が変わるだけにします（点滅などはしない）。

### 10.2 アクセシビリティ
- 文字と背景の明るさの差（コントラスト比）は、本文で4.5:1以上、大きな文字とアイコンで3:1以上にします。
- 色だけで状態を伝えず、凡例・文字・チェックの印を合わせて使います。
- 人体図には、画面読み上げ用の説明（例：「大胸筋：疲労中、あと38時間」）を付けます。
- 端末の文字サイズの設定を大きくしても、表示が崩れないようにします（文字の大きさは `rem` で指定）。
